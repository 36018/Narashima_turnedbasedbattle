Voor het project Myth, konden we kiezen uit verschillende myths. 
Wij kozen voor de myth Narashima. 
"De legende van Narasimha (ook wel Narasimha Avatar) komt uit het hindoeïsme en gaat over een van de tien incarnaties (avataras) van de god Vishnoe. 
Narasimha betekent letterlijk “man-leeuw” — hij is half mens, half leeuw."

Als groep moesten wij een turnedbased battle maken over de myth Narashima
